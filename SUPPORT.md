# Getting help with RuneTranslate

This repository is RuneTranslate's public information hub. The app itself is closed-source and is distributed from **[runetranslate.com/download](https://runetranslate.com/download)**, so most problems are answered fastest by the app itself or by the docs here.

## Where to go

**1. The app's own diagnosis page.** If a translated game will not start, run it. It checks the game folder, what the export delivered, fonts and encoding, translation coverage and the game's own crash log, then offers a safe-mode build. Free on every tier.

**2. [docs/troubleshooting.md](docs/troubleshooting.md)** — the common problems and what actually fixes them.

**3. The guides** at **[runetranslate.com/blog](https://runetranslate.com/blog)** — an end-to-end walkthrough for most engines, plus write-ups on fonts, patches, glossaries and providers.

**4. The FAQ** at **[runetranslate.com/faq](https://runetranslate.com/faq)**.

**5. Support tickets, from inside the app.** *Support* files a real threaded conversation that gets a reply in the same place — with screenshots (Ctrl+V pastes one straight in), spreadsheets or a `.rtpatch` attached. **Free on every tier**, because support should not be a paid feature.

**6. [Discord](https://discord.gg/ZtsfZu7YsW)** — the community. Best for *"has anyone translated this game before?"*, engine requests, and a second opinion on a provider.

## What to include in a report

- The **engine** (or the game, so we can work it out)
- The **app version** — the About page has a one-click diagnostics block that includes it
- What you expected, and what happened instead
- Whether the **original**, untranslated game runs on your machine
- A screenshot, if it is something you can see

## Requesting an engine

Most of the engines RuneTranslate handles today were added because somebody sent in a game that would not open. Ask on [Discord](https://discord.gg/ZtsfZu7YsW), or email **runetranslate@gmail.com** with the game and a listing of its folder.

## Security

If you believe you have found a security issue, please report it privately through an in-app support ticket or [Discord](https://discord.gg/ZtsfZu7YsW) rather than opening a public issue.
